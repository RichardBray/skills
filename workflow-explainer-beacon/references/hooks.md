# Hooks

## Instagram research (Nov 2026)

16 Reel searches through Alexandria (`scrapecreators` `instagram/search-reels`, 2 credits each; read big results with the `firecrawl` `bash` workspace and `jq`, no `@tsv`). About 150 AI and tech Reels. View counts are Google-indexed and captions stand in for the spoken hook, so treat this as direction.

| Pattern | Views seen |
|---|---|
| "This is the craziest/wildest ChatGPT use case I've ever seen", then the action at once ("You start by taking a photo of...") | 2.39M, 1.56M, 367K, 221K |
| "My <thing> now runs on Claude" (show the whole system) | 1.6M |
| "Most people / 99% of people don't know..." | 228K, 145K, 101K, 76K |
| Problem, then fix ("How to make ChatGPT stop lying") | 162K |
| "Claude can now..." | 26K-62K |
| "Apparently you can now..." (a discovery, not a joke) | 44K, 31K, 8K |
| "Before you <buy/sign>..." | 13K |

"Apparently ChatGPT knows me" trend jokes stayed under 20K. The owner dislikes the "craziest use case" opener for these videos.
