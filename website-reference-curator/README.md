# website-reference-curator

Owns the shared website reference library that [`reference-led-websites`](../reference-led-websites) reads: site records, evidence, discovery tracking and component suppliers. See that skill's README for the build workflow.

This skill collects and maintains references. It does not build client websites.

## Installation

```sh
npx skills add https://github.com/RichardBray/skills --skill website-reference-curator
```

Install it as a sibling of `reference-led-websites` and the builder finds the library automatically.

## Prerequisites

- Python 3 for `scripts/catalog.py` and its tests (standard library only).
- A browser or web tool for inspecting sources. Firecrawl and its design-clone workflow are used when available; anything else works, and the skill records which was actually used.

## What ships with it

`library/` is seeded, not empty: 8 reviewed sites (Ali Two Times, AQuest, Floema, Goodboy, Lando Norris, Lusion, MANA, United Carriers), each with a branding extraction and a motion audit, plus a discovery inventory of further candidates and a component supplier list. `catalog.csv` and `motion-catalog.csv` are derived views, regenerated by the export commands.

## Usage

```
/website-reference-curator add https://example.com to the library
```

Also handles award-collection URLs, component sources, corrections to existing records, and library health audits.

Read-only search, which the builder also uses:

```sh
python3 scripts/catalog.py search --query 'editorial restrained hospitality' --limit 8
python3 scripts/catalog.py search --tag scroll-reveal --status reviewed
```

After any library change:

```sh
python3 scripts/catalog.py validate
python3 scripts/catalog.py export-csv --output library/catalog.csv
python3 scripts/catalog.py export-motion-csv --output library/motion-catalog.csv
```

After a schema or tooling change, also run the regression tests:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
```

## How records stay trustworthy

Motion is never inferred from still images, technology is never inferred from appearance, and reuse rights are never inferred from an asset URL. Unknowns stay recorded as unknowns. Validation proves structural invariants only, not that a site was reviewed well.
